# Advanced Video Player (Android) 🎬

A modern, high-performance Android Video Player application built using **Kotlin** and **AndroidX Media3 (ExoPlayer)**.

## ✨ Features
- **ExoPlayer (Media3)** engine for smooth, hardware-accelerated playback.
- **Format Support:** MP4, MKV, WebM, HLS (`.m3u8`), DASH (`.mpd`), and more.
- **Local Video Picker:** Select and play any video file directly from device storage.
- **Network Streaming:** Direct stream playback from HTTP / HTTPS URLs.
- **Playback Speed Control:** Toggle speeds (0.5x, 0.75x, 1.0x, 1.25x, 1.5x, 2.0x).
- **Aspect Ratio Switching:** Fit, Fill, Zoom, Fixed Width, and Fixed Height modes.
- **Picture-in-Picture (PiP) Mode:** Multi-tasking support with background floating window.
- **Auto GitHub Actions Build:** Automatically compiles and generates APK artifacts on push.

---

## 🚀 How to Download / Build APK via GitHub Actions

1. Push your changes to GitHub or trigger the workflow manually.
2. Go to your repository on GitHub.
3. Click the **Actions** tab at the top.
4. Select the **Build & Release Android APK** workflow.
5. Once the run completes, scroll down to the **Artifacts** section and download `AdvancedVideoPlayer-Debug-APK.zip`.
6. Extract the zip file to get `app-debug.apk` and install it on your Android phone!
